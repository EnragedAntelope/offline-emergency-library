- **A failed size check no longer joins two editions of a PDF or model.** When the server does not give a file's size (a failed HEAD, or a host such as iris.who.int that answers every HEAD with an error), both installers used to resume the download onto the copy already on the drive. If the publisher had replaced the file with a bigger one, the result was the old file's start plus the new file's end. It still began with `%PDF`, and later runs kept it because its size then matched. Now a finished copy is kept, and a missing file downloads whole to a part file that replaces nothing until it is complete. Resolves #289.
