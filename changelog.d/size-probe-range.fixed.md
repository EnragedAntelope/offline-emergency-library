- **New editions of the WHO PDFs arrive again.** iris.who.int answers every size request (HEAD) with an error, so both installers never learned the size of the two WHO PDFs: a newer edition never replaced the copy on the drive, and a copy cut short by an interrupted run was kept. When HEAD gives no size, the installers now ask for the file's first byte and read the full size from the server's answer, trusting it only when the server sends just that byte (a 206). A server that ignores that request is stopped before it sends the whole file, and the size stays unknown, as before. Files whose HEAD already works are unchanged. Follow-up to #289.
